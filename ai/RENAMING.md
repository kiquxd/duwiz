# Переименование ya-ncdu в duwiz

Статус: реализовано локально 23 августа 2026 года.

`duwiz` расшифровывается как **du wizard**. Новое имя используется для CMake
project/target, исполняемого файла, установленной команды, заголовка TUI,
Docker entrypoint/image examples, help и пользовательской документации.

Единственная переменная выбора image backend — `DUWIZ_IMAGE_BACKEND`. Проект
пока не имеет опубликованного compatibility contract, поэтому alias для старого
названия не сохраняется.

Переименование исходников не меняет автоматически GitHub repository, локальное
имя каталога или `origin`. После переименования репозитория на GitHub локальный
checkout нужно перевести командой:

```sh
git remote set-url origin git@github.com:kiquxd/duwiz.git
```

Старый бинарник `build/ya-ncdu` может физически остаться в уже существующем
build-каталоге как устаревший артефакт. Новая CMake-сборка создаёт и
устанавливает только `duwiz`.
