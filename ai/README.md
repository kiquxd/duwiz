# AI handoff directory

Agent-authored project notes for duwiz belong in this directory. Product source,
tests, CMake files and the user-facing README stay in their normal locations.

- `RENAMING.md` records the product rename and compatibility decisions.
- `TEXT_PREVIEW.md` records line-number and search-style integration.
- `DELIMITED_PREVIEW.md` records CSV/TSV table rendering.
